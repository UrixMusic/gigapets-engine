Paint
Turn on Paint, click a tile in the sheet below to pick a brush, then drag on the map. Right-click a map cell to copy its tile. Replace all: click a cell and every matching tile in this area becomes the brush (the faint preview shows which cells change). Ctrl+Z undoes the last action. Nothing is saved until Export ROM.
Move
Turn on Move, then drag an object or NPC to reposition it, or a spawn point (turn on "item spawn points" too; y-order is left as it is), or drag a path waypoint (small square on an NPC path) to reshape its route. Objects are re-sorted by Y when dropped, since the game keeps them Y-sorted. Waypoints can be moved but not added or removed (the list has no spare room), and NPCs sharing a path list will all change. Edits live in the loaded ROM until Export ROM.
NPC properties
Replace with another NPC
Select an NPC with the Move tool or the list. Values are the raw record words, written to the loaded ROM (undoable) and saved by Export ROM. Replace copies the source's stats, odds, wander data, behaviour flags, species and appearance. Changing Area sends the NPC to another map, so it disappears from this one. For stationary NPCs, Species / anim is an animation ID; for roaming ones 0 dog, 1 monkey, 2 panda, fffe = your pet's species.
Object editor
Select an object from the list or by clicking it (not in Paint mode). Retyping keeps the object's index, so it is always safe. Delete shifts the index of every later object, and the game keys its per-object progress bits by index, so it is blocked when any later object is interactive unless you tick the box. Deleting is blocked for tables shared by several areas. The freed slot is zeroed. Both are undoable.

Tileset Sprites
Double-click any tile in the sheet to edit it in the sprite editor
Tiles open in the same sprite editor as sprites (pencil, fill, replace, palette colour editing, zoom, undo, its own PNG import), as one piece with the sheet's palette. In the editor, colour index 0 is drawn as transparent even if this palette's entry 0 is opaque on the map. Indexed PNGs keep the palette (transparent entries and flagged colours are see-through); the zip adds manifest.json and the palette. Import snaps each pixel to the nearest colour of the current palette (an indexed export round-trips exactly) and writes raw indices to the ROM; undoable. Select the same area / sheet / palette base on import as on export. A tile can appear in many maps and palette edits affect every area using that palette.

Help
Red outlines: tile IDs past the sheet. Click an object to highlight its type, or bare ground to highlight a tile ID. Interiors may use another sheet or palette, so their art can look wrong. Mouse wheel zooms at the cursor, middle-drag pans. Shortcuts: P paint, M move, C collision, O objects, N NPCs, [ and ] zoom.
