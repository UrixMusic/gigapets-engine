(or a single mod folder). Needs Chrome or Edge.
Selected
Click an object or NPC. With the Move tool, drag it. Del removes it, arrows nudge it.
Paint tiles
Brush tile
Click a tile to pick it. With the Paint tool: drag on the map to paint, right-click a map cell to copy its tile. On a base area this saves a set_tiles patch; on a mod's own area it edits the map.
Place objects
Pick a type, choose the Place tool, then click the map: the click is the object's feet.
New area
The map starts filled with the most common tile of the area you borrow from; then paint it. Make a door to it from the Selected panel. A mod area has no random finds, shops or digging yet.
New NPC
no picture
A single PNG, feet at the bottom middle. Click the map to put them down. NPCs drawn from a PNG show their picture; base-game NPCs show as dots. Move and delete work on every NPC.
This area
The base game's outdoor areas dig; a mod area can too. Random finds need spawn points (the "Spawn pts" layer shows them).
Off by default, like the base game: a save made here starts at home next time. On, a save made here starts here, at the same spot. It is an area setting, so it works on any area, mod or base.
Game tables
Pet colours
Make a colour for the pets (the player's pet, and the roaming pet NPCs) and see it live on the animations. It is saved as a palette record; tick "offer in the colour change machine" to let players pick it there. Needs the pets.json that --export-base writes next to base.json.
Mod changes
How it works
Your edits are written to data/zz_gigaeditr.json in the mod you are editing, as object / area / objtype / text / npc records, and, from the Game tables panel, find / spot / quest_spawn / gate rows (add, patch, remove). The file sorts last, so it wins over the mod's own files. Other files are never touched, and the ROM is never changed. New PNGs go to assets/. Mods are applied in the game's load order; a later mod overwrites an earlier one, shown in orange. Not yet: new areas, new NPCs, tileset editing (use Aseprite for tile art).
